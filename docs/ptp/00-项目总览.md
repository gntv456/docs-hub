# PTPatronus 项目总览

## 这是什么

PTPatronus（**PT 守护神**）是一款 PT 站管理工具，从原 Kotlin Multiplatform 项目推倒重写为 **Go 后端 + Vue3 Web UI + Flutter 客户端**。

## 核心价值

- **7×24 自动化保号**：后端常驻 Docker，自动签到/统计同步/cookie 保活/H&R 告警/注册开放检测，手机不用开
- **多站统一管理**：20 个 NexusPHP 站点 + 馒头（M-Team JSON API）开箱即用（好学/财神/OurBits/HDSky…），新增 NexusPHP 站 5 行 YAML
- **下载器控制**：qBittorrent（rid 增量同步）+ Transmission，一个界面管所有
- **媒体匹配**：TMDB + 豆瓣（微信 UA 免签名 frodo，国产内容主源）+ Bangumi（动漫/三次元）+ MusicBrainz 海报/元数据匹配 + NFO 生成
- **安全**：限流防爆破 + CORS 收敛 + JWT/APIKey 双轨 + 全链路审计日志
- **跨端**：Docker（API+Web UI 单镜像）/ Android / iOS / Mac / Windows / 鸿蒙（需华为 Flutter 分支）；移动端已支持搜索→下载完整 PT 流程 + 仪表盘真实趋势 + 媒体海报搜索 + 娱乐游戏 + 备份导入导出 + 文件浏览/传输 + 设备监控（含摄像头 HLS 实时画面）；Web/移动端均可一键导出仪表盘概览分享图（客户端出图，零新增依赖）
- **设备监控**：服务器/NAS/摄像头统一监控（本机 gopsutil + 远程 SSH + Agent 上报 + 群晖/TrueNAS/SNMP + ONVIF），摄像头 RTSP 实时预览，阈值告警复用通知链
- **站点信息聚合**：站免（全站免费/促销横幅）+ 公告（结构化站点公告）+ PT监护室（聚合 savept.icu 站点健康与本地站点匹配），cron 定时刷新缓存 + WS 推送正在站免
- **站点用户管理**：后宫（邀请库存 + 被邀请人花名册 + 药单导出）+ 站点考核（per-platform 真实进度 + DB 历史趋势）+ 消息（私信聚合 + 回复/删除/标记已读写操作）+ 勋章墙（跨站勋章商店聚合 + 购买/佩戴/摘下 + 价格/上架/售罄提醒，per-platform 4 套解析器）
- **种子浏览与媒体发现**：种子详情页解析（简介/截图/MediaInfo）+ 推荐（豆瓣/TMDB/Bangumi 多源热门信息流）+ 探索（关键词跨源搜索），一键「在站点查找」按需联动既有跨站搜索

## 技术架构一句话

Go 后端为核心（Docker 部署）→ Vue3 Web UI（go:embed 内嵌）+ Flutter 客户端（含鸿蒙）

## 关键数字

| 维度 | 数量（2026-08 复核，随代码漂移请以实际为准） |
|---|---|
| 后端 Go 代码（非测试，含 cmd） | ~9 万行（`git ls-files 'backend/**/*.go'` 口径 1165 文件；internal 非测试约 1.5 万行的老口径已不适用——项目已从 6 月底骨架长成全功能系统） |
| 后端 internal 包 | 47 个业务域（site/cloud/plugins/aiagent/media/monitor…） |
| 测试函数 | 1844 个（`go test ./... -short` 全绿，CI 带 -race） |
| Web UI 视图 | 47 个 views/*.vue + 171 个组件 |
| 站点定义 | 304 个 YAML + NexusPHP 模板（5 行/站零代码新增）+ 馒头 JSON API |
| Schema 适配器 | nexusphp HTML / mteam JSON / rousi 等 + 考核与勋章墙 per-platform 子包 |
| 移动端 | 40 个 feature 模块（Android/iOS/macOS/Windows/鸿蒙） |
| 浏览器扩展 | MV3，v2.6（站点白名单动态注入，见 extension/sitelist.js） |
