## v1.4.2（2026-10-16，提醒可靠性与外部文件导入）

> 来源：2026-10-15 的深度用户视角测试（见 `docs/DEEP-TEST-2026-10-15.md`），修的是「能力在、路没通」那一类问题。

### 修复
- **重启手机后提醒不再丢失**：Android 的待发闹钟不跨重启存活，此前只有前台 Shell 启动才会重排 —— 用户重启一次手机，所有上课 / 作业 / 考试提醒就静默消失，直到下次主动打开 App。新增 `BootReceiver`（开机 / 应用更新 / 改时间 / 换时区四类广播）经 headless FlutterEngine 触发整轮重排，全程不建 Activity（不会开机蹦出界面）；manifest 补 `RECEIVE_BOOT_COMPLETED`。
- **提醒改回精确闹钟**：此前一律用 `inexactAllowWhileIdle`，Doze / 息屏下可延迟数十分钟到数小时，「上课前 10 分钟」形同虚设。现在申请 `SCHEDULE_EXACT_ALARM` 并探测可用性，拿不到时自动降级为非精确（宁可晚一点，不是没有），设置页新增「提醒准时性：当前为『可能延迟』」入口可一键去授权 —— 拿不到权限这件事必须让用户看得见。刻意不用 `USE_EXACT_ALARM`（那是闹钟 / 日历类应用的专用权限）。
- **回归测试时间炸弹**：`calendar_makeup_badge_test` 把学期起点锚在「今天所在周的周一」，10 月唯一补班日 10-10 早于 10-12 起的各周一，于是从 10-12 起每天跑必红（产品答「无课」是对的，是期望写错了）。改为锚在补班日所在周的周一，「补班日落在学期内」变成构造保证。

### 新增
- **「用其他应用打开」直接导入课表文件**：微信 / 邮件 / 文件管理器里收到 `.ics` / `.csv` / `.json` / `.xlsx` / `.html` 时可直接选本 App 打开，落到导入预览。解析能力一直都在，缺的是入口 —— manifest 此前只有 MAIN 与 `kechengbiao://`。安全上做了两层：原生把文件复制进 `cacheDir/incoming/` 后只传**裸文件名**（系统给的 URI 不透传给 Dart，否则外部应用可借 URI 诱导本 App 读私有文件），Dart 侧再校验一次（拒绝路径分隔符 / `..` / 白名单外扩展名）。
- **全局搜索覆盖全部学期**：此前只搜当前学期，「我明明记得学过这门课却搜不到」；现在结果行会标出所属学期（归档学期标「已归档」），两个学期的同名课不会再分不清。

### 清理
- 删除小组件数据契约里的死字段 `nextStartMinute` / `nextEndMinute`：Dart 每次同步都写，但五个 Kotlin Provider 与 ArkTS 侧零读取（原生实际用 `weekLessons[].startMinute/endMinute` 调度）。留着只会让下一个改卡片的人以为它已接线。
- 通知重排的装配收口到 `lib/application/reschedule_runner.dart`：前台与开机后台共用同一份解析器构造，避免漂移只在「重启过手机」这类路径上现形。

### 验证
- `flutter analyze` 0 issues；`flutter test` **1356 全绿**（新增：后台重排握手与装配 3 例、外部文件名校验 6 例、搜索学期标签 3 例、精确闹钟模式 3 例、搜索结果行学期标注 1 例、设置页准时性入口两态 2 例）。
- `flutter build apk --debug` 通过（Kotlin 侧新增 `BootReceiver.kt` / `IncomingFileHandler.kt` 编译与打包验证）。

## v1.3.2（2026-10-09，桌面卡片不加载终局）

## v1.2.10（2026-10-07，白屏终极根因轮）

> 用户报告 v1.2.9 后白屏依旧。本轮放弃纯静态分析，在模拟器上完整复现用户操作路径并逐帧取证，抓住白屏的真正机制链，三处修复全部实证归零。

### 根因（模拟器复现 + 日志实锤）
- **机制一（启动即白屏）**：冷启动深链（intent 带 URL）会让引擎把整个 URL 塞进 `defaultRouteName`，框架的初始路由生成器按 URL 逐段 push 出一整屏空白页（截图 17KB 纯白实锤）。
- **机制二（返回后白屏，用户主诉）**：通知/深链跳转用的 `go()` 会**替换整个路由栈**——目标页成为栈中唯一页面，用户按返回把它弹掉 = 空栈，触发 go_router `popped the last page` 断言 + Navigator `!_debugLocked` 锁断言（pop 后的壳/导航器重建落在锁窗口内），渲染树损坏 → 持续白屏需杀进程。模拟器同路径 100% 复现两代断言。

## v1.2.9（2026-10-07，启动断言终局定位轮）

> v1.2.8 干净会话日志仍出现 2 次 `Null check operator` 断言（framework `app.dart:1551`）。本轮通过逐步升级的运行时取证（完整 20k 字符堆栈 + 断言瞬间导航环境快照 + 帧尾 MaterialApp 全树普查 + 引擎 defaultRouteName 记录）在模拟器上稳定复现并定位真凶。

### 根因（实证）
- 断言点并非表面上的 `routes!`——**1551:48 是 `widget.home!`**（本地 SDK 源码逐列核对）。启动流程中 Splash/登录壳（`MaterialApp(home:)`）与主界面壳（`MaterialApp.router`）**是同一位置的同一类型 widget，State 被复用**：换壳时旧根路由的页面构建闭包 `() => widget.home!` 仍存活，下一帧 dirty 重建（由 MediaQuery 等 InheritedNotifier 变化触发）执行它，此刻 `widget` 已是 router 形态、`home == null` → 空断言。每次冷启动换壳两次（Splash→登录/引导→router），正好对应日志里固定的 2 次。
- 完整堆栈特征（此前被误读为 pushNamed）：底部是 `BuildScope._flushDirtyElements → WidgetsBinding.drawFrame` 的普通脏元素重建，中间无任何 `NavigatorState.push`/`handlePushRoute` 帧——否定了「平台推送路由」假说；`didPushRouteInformation` 拦截日志为空也交叉印证。

### 修复
- **两个壳形态各自独立 key**（`ValueKey('router-shell')` / `ValueKey('nav-shell')`）：换壳 = 旧 MaterialApp State 连同旧路由闭包整体销毁，不再出现「旧闭包读新壳 null home」的窗口。模拟器连续 4 次冷启动断言归零（diag_log + logcat 双确认）。
- **平台推路由拦截器**（`AppLoggerLifecycleObserver` 实现 `didPushRoute/didPushRouteInformation`，注册于 main() 先于 runApp）：非 router 壳存活期直接消费引擎推来的路由（登录/引导期本就无页可跳，留痕忽略），router 壳期放行给 GoRouter。防御外部深链落入无路由表的壳。
- 取证代码收敛：断言堆栈记录上限回调 4000 字符；`defaultRouteName`、断言时导航环境快照、帧尾壳普查保留在诊断日志中（下次真有问题可直接读日志定位）。

### 修复
- **学期切换自愈加固（build 4）**：修好后自愈逻辑原在 build 期间直接 `jumpToPage`（build 期非法，实际被跳过导致修复无效）——回归测试暴露后改为帧尾（`addPostFrameCallback`）钳制周数并跳页。新增学期切换回归测试（手动周次 18 → 切 4 周学期，胶囊自愈回 1~4）。
- **测试专家对抗性审查（2026-09-05，build 3）**：全量代码审查 + 对抗性测试发现并修复 14 项缺陷——
  1. **致命｜节次时间滚轮双轴互相覆盖**：`_WheelPicker` 用 `late final` 固定初值且闭包引用对方轴的**陈旧值**，先滚小时再滚分钟会把上课时间存成「初始小时+新分钟」（如选 14:30 实际落库 08:30），直接污染整张课表作息。改为可变状态互相同步（新增 3 条对抗性回归）。
  2. **高｜ICS 导出未按学期过滤**：多学期时每门课对每个学期各生成一个事件（事件翻倍且一半锚错开学日），「仅导出某学期」也会带出其他学期的课。已按 `course.termId` 过滤。
  3. **高｜ICS TEXT 字段零转义**：课程名/地点含换行、分号、逗号、反斜杠会破坏 VEVENT 结构（Google Calendar 等严格解析器拒收整份文件）。按 RFC 5545 转义。
  4. **高｜JSON 导入零数值校验**：`totalWeeks=-5` 会让课表页 `itemCount` 断言崩溃；`totalWeeks=2e9` 会在解析器 `List.generate` 处 OOM；天文 `startDate` 溢出 `Duration`。导入入口统一范围钳制（越界抛 `FormatException` 事务回滚）。
  5. **高｜竞品导入 `step` 别名错误**：`step` 是「连堂节数」却被放进结束节次别名表，超级课程表 2-3 连堂会被截断成 2-2（静默丢课）。已从别名表移除并单独按节数展开。
  6. **高｜`WeekCodec.maxWeek=25` 与 UI 允许的 30 周学期冲突**：第 26-30 周被静默吞掉，且再次编辑会被重写成整学期（二次数据损坏）。上限提升到 30。
  7. **高｜当前课呼吸高亮永不启动**：`_CourseBlock` 只在 `initState` 建动画，上课时刻到来后（30s 心跳刷新）无 `didUpdateWidget`，正在上的课永远无高亮；反向场景动画空转。已补 `didUpdateWidget` 启停。
  8. **高｜学期切换后周次越界不自愈**：20 周学期翻到第 18 周后切到 4 周学期，顶部胶囊显示「第 18 周」而网格停在第 4 周。`_ensureInit` 检测学期/周数变化后钳制并跳页。
  9. **高｜编辑页冲突检测用全局作息**：学期有专属作息时误报/漏报（全 App 其他链路均已用学期作息）。改用 `getPeriodsOfTerm`。
  10. **中｜拖拽落点冲突检测无分钟维度**：候选片段不传分钟，「自定义时间横跨多节」的既有课漏检；且既有片段的自定义分钟传入后被忽略（死参数）。候选与既有片段均回填作息分钟。
  11. **中｜极短自定义时间负高度崩溃**：自定义 3 分钟的块换算高度 <4px 时 `Positioned` 负高度触发布局断言。高度下限 12px。
  12. **中｜节次下拉越界断言崩溃**：`maxPeriods` 调小后打开旧课（或深链超界节次），`DropdownButton.value` 不在 items 内直接断言崩溃。value 钳制兜底。
  13. **中｜学分无范围校验**：`-3`、`1e2` 均可入库。现要求 0~100。
  14. **低｜其他**：深链 `/course/abc` 路由 `int.parse` 抛异常白屏（改 `tryParse` 兜底）；学分 2.25 经 `toStringAsFixed(1)` 往返丢失为 2.3（改 `toString`）；清空周次的片段保存被静默展开成整学期（改为确认弹窗+跳过）；「开学在未来 7 天自动取消切换」阈值随时钟漂移（改按日期比较）。
