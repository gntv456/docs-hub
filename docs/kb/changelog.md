## v1.1.3（2026-09-14，竞品对标修复轮 · 第三段）

> 补齐 §7 里最后一项代码层可闭环的 GAP：**G-08 调课 / 调休例外层**。

### 新增
- **调课工具**（设置 → 日期之间调课，或课表设置区入口）：可以给任意一天设置
  - **这天停课（不补）**；
  - **整天调到本周另一天**（目标日限制在同一自然周）。
  课表页会给出反馈：调课过来的课程块带「调」角标，停课 / 调课的当天有一整列提示带（「停课」「调至周三」），不会让用户对着空白的一天猜数据是不是丢了。
- **例外是可撤销的**：调课工具里列出本学期所有例外，点删除即恢复原样。
- 数据层新增 `schedule_overrides` 表（schema v5），随导出 / 导入 / 本地快照一起走；导入时会校验类型（只允许停课 / 调课），非法值整体回滚。

### 修复
- **高｜课表与通知会各说各话**：课程提醒的排期现在与课表渲染**共用同一份解析**（`core/util/day_override.dart`）。停课的那天不再发提醒；调到别的日子的课，提醒也跟着挪到目标日。

### 变更
- **原课表永不被修改**。调课是「按日期生效的例外」，只影响指定日期所在的那一周；这是与竞品最大的做法差异 —— 直接把课表改掉会让之后每周都跟着错。
- 目标日已被占用的节次**不会被静默丢弃**：这部分课程留在原处，并在确认框里明确告知「其中 N 节因目标日该节次已被占用，会留在原处」。
- 跨周调课**明确拒绝**（日期选择器直接限制在本周内），而不是算出一个用户看不懂的结果。
- 例外块**禁止长按拖拽**：拖拽改的是原课表（之后每周都变），与「只改这一次」的意图冲突。

### 已知未完成（见 `COMPETITIVE-ANALYSIS.md` §7）

- **测试专家对抗性审查（2026-09-05，build 3）**：全量代码审查 + 对抗性测试发现并修复 14 项缺陷——

  2. **高｜ICS 导出未按学期过滤**：多学期时每门课对每个学期各生成一个事件（事件翻倍且一半锚错开学日），「仅导出某学期」也会带出其他学期的课。已按 `course.termId` 过滤。
  3. **高｜ICS TEXT 字段零转义**：课程名/地点含换行、分号、逗号、反斜杠会破坏 VEVENT 结构（Google Calendar 等严格解析器拒收整份文件）。按 RFC 5545 转义。
  4. **高｜JSON 导入零数值校验**：`totalWeeks=-5` 会让课表页 `itemCount` 断言崩溃；`totalWeeks=2e9` 会在解析器 `List.generate` 处 OOM；天文 `startDate` 溢出 `Duration`。导入入口统一范围钳制（越界抛 `FormatException` 事务回滚）。
  5. **高｜竞品导入 `step` 别名错误**：`step` 是「连堂节数」却被放进结束节次别名表，超级课程表 2-3 连堂会被截断成 2-2（静默丢课）。已从别名表移除并单独按节数展开。
  6. **高｜`WeekCodec.maxWeek=25` 与 UI 允许的 30 周学期冲突**：第 26-30 周被静默吞掉，且再次编辑会被重写成整学期（二次数据损坏）。上限提升到 30。
  7. **高｜当前课呼吸高亮永不启动**：`_CourseBlock` 只在 `initState` 建动画，上课时刻到来后（30s 心跳刷新）无 `didUpdateWidget`，正在上的课永远无高亮；反向场景动画空转。已补 `didUpdateWidget` 启停。
  8. **高｜学期切换后周次越界不自愈**：20 周学期翻到第 18 周后切到 4 周学期，顶部胶囊显示「第 18 周」而网格停在第 4 周。`_ensureInit` 检测学期/周数变化后钳制并跳页。
  9. **高｜编辑页冲突检测用全局作息**：学期有专属作息时误报/漏报（全 App 其他链路均已用学期作息）。改用 `getPeriodsOfTerm`。
  10. **中｜拖拽落点冲突检测无分钟维度**：候选片段不传分钟，「自定义时间横跨多节」的既有课漏检；且既有片段的自定义分钟传入后被忽略（死参数）。候选与既有片段均回填作息分钟。
  11. **中｜极短自定义时间负高度崩溃**：自定义 3 分钟的块换算高度 <4px 时 `Positioned` 负高度触发布局断言。高度下限 12px。
  12. **中｜节次下拉越界断言崩溃**：`maxPeriods` 调小后打开旧课（或深链超界节次），`DropdownButton.value` 不在 items 内直接断言崩溃。value 钳制兜底。
  13. **中｜学分无范围校验**：`-3`、`1e2` 均可入库。现要求 0~100。
  14. **低｜其他**：深链 `/course/abc` 路由 `int.parse` 抛异常白屏（改 `tryParse` 兜底）；学分 2.25 经 `toStringAsFixed(1)` 往返丢失为 2.3（改 `toString`）；清空周次的片段保存被静默展开成整学期（改为确认弹窗+跳过）；「开学在未来 7 天自动取消切换」阈值随时钟漂移（改按日期比较）。
