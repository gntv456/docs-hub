## 0. 结论摘要（先看重点）

1. **最严重的问题不在功能缺失，而在口径与实现相反。** 三处产品级承诺与代码直接冲突：
   - `settings_page.dart:598` 写「不注册、不登录即可使用全部本地功能」，但 `app.dart:304-309` 在未登录时一律换壳到 `LoginPage`，登录页只有「登录」和「诊断连接」两个动作（`login_page.dart:348-356, 1118-1121`），**没有游客/跳过/注册入口**。首次使用必须能连上 `hxpt.org` 或 `ptang.top`（`auth_models.dart:111-121`）并持有账号。
   - `onboarding_page.dart:48` 写「支持教务站点快捷登录，账号信息仅用于同步你的学习进度」，而教务导入是 `NoopAcademicImportClient`（`fetchTerms` 直接 `throw UnsupportedError`），云同步是 `NoopSyncClient`。**引导页在承诺两个不存在的能力。**
   - `docs/P3-ROADMAP.md:33` 自订原则「学校账号、AI 图片、同步 token 不写入导出备份明文」，而 `data_io.dart:152` 把 `settings` 整表原样导出（含 `auth_session`），导入时 `:315` 先删表、`:469-471` 原样回写 → **备份/分享备份文件即转移登录态**。

2. **录入自动化是四个参照物共同的主战场，也是我们最大的空洞。** 嘎嘎内置 1542 所高校索引 + 10 种教务系统指纹；Nexio 走外置脚本仓库 248 校/273 适配器；Dawn 有 5 条导入路径 + 可远程下发的签名脚本。我们**已经写好一套 ~1150 行的声明式教务脚本引擎（`lib/data/integrations/adapter/`），但全仓零调用点、零随包脚本**（正控见附录 A.4），等于功能不存在。

3. **实测复现出两个「静默毁数据」的导入缺陷**（附录 A.1/A.2）：
   - WakeUp **官方 CSV 模板原样导入 → 识别 0 条课程**。原因：两张别名表分裂在两个解析器里，各缺一半——`local_schedule_recognition_client.dart:184-206` 认 `课程名称` 却不认 `开始节数/结束节数/周数`；`competitor_schedule_parser.dart:153-166` 认 `周数` 却不认 `课程名称/开始节数`。
   - `1-5、7-11单、12-16双`（WakeUp 文档明写的官方写法）被解析成 **`1,3,5,…,15`（全单周）**。根因在 `competitor_schedule_parser.dart:264-265` 用「整串是否含『单』/『双』」做全局判定，`:308-311` 再按这个全局标志过滤所有已展开周次——混合写法必然错，且错得毫无提示。

4. **课表数据模型比三个参照物都弱一档：教室与老师挂在「课程」上，而不是「排课片段」上。** `tables.dart:60-72` 的 `ScheduleSlots` 没有 `location`/`teacher`/`color` 列。嘎嘎的 `SessionRule` 有 `location?/teacher?/teacherPhone?`（`types.ts:53` 附近），Dawn 的 `CourseEntity` 一行即一个「星期×起始节+节数×周区间」并各带 location/teacher。后果：**「周三在 A101、周五在 B203」无法表达**，只能拆成两门课或写进备注；换教室只能靠整日停课例外兜。

5. **系统级触达：Android 一条腿站稳，iOS 完全没有腿，提醒可靠性落后于全部参照物。** 我们只有 1 个 Android 小组件（`TodayClassWidgetProvider.kt`，4×2）；嘎嘎 4 款（今日/下一节/两日/本周）+ `requestPinAppWidget` 一键添加；WakeUp 文档列 Android 4 款 + iOS 5 款 + 鸿蒙 6 款；Nexio 手机/Pad 各 2 套 + MTZ 主题组件。提醒侧，我们用 `AndroidScheduleMode.inexactAllowWhileIdle`（`notification_provider.dart:416`），manifest **没有 `SCHEDULE_EXACT_ALARM`/`USE_EXACT_ALARM`**，也**没有 `RECEIVE_BOOT_COMPLETED`**（`AndroidManifest.xml:2-3, 59-66`）→ Doze 下延迟、重启后不重排。Nexio 注释直接写了「曾用非精确闹钟，漂移累积致 Doze 延迟数小时，已移除勿再引入」；Dawn 用 `USE_EXACT_ALARM` + 三级降级 + 非精确 15 分钟宽限；嘎嘎干脆把提醒全部交给**系统日历**（零本地通知代码）。

6. **月历不吃调课例外，是全仓唯一一处「同一份数据两种答案」的一致性破口。** `calendar_page.dart:139-145` 只按原始 `dayOfWeek + WeekCodec.decode(weeks)` 过滤，从不引用 `resolveWeekPlan`（9 个文件引用它，含周视图/今日/通知/小组件/ICS 导出）。停课的日照常有课，调到今天的课不出现。既有 `calendar_link_test` 只测周映射，测不到这一条。

7. **还有一批「看得见、点不动」的细节**：`timetable_settings_page.dart:177-185` 的「将此课表配置用作默认配置」是一句**纯 Text，没有任何控件**；`Terms.isArchived` 有列、有导出、有「已归档」徽标（`schedule_page.dart:1289,1298`）却**没有任何写入 UI**；`wallpaperAccent` 等 4 个设置键零消费者；全仓 **0 个 `PopupMenuButton`/`showMenu`**（长按只有拖课）、**0 个 `Dismissible`**、**没有任何搜索**。

## 4. 缺口清单与建议

级别：**P0** = 定位/信任/增长硬门槛；**P1** = 首轮迭代；**P2** = 规划。

### 4.1 P0

**G2-01 口径统一：先让产品说自己真话**（对应摘要第 1 条）
- 三处文案与代码冲突。修法二选一：① 打开游客态（`app.dart:304` 允许无 session 进主界面，登录降级为「同步/口令」的可选动作，同时删掉引导页第 5 屏的教务承诺）；② 保留门槛，把 `settings_page.dart:598` 改成真实描述（「首次需绑定好学堂账号，课表数据仍只存本机」）并删掉教务承诺文案。
- 建议选 ①：三个参照物都不做强制账号（§1），而「无广告 · 不注册 · 本地优先」正是我们对外主打的差异化。
- 验收：新增一条断言测试「无 auth session 时可到达 MainShell」；引导页/关于页每条承诺都能指到一个真实实现或真实状态页。

**G2-02 教务导入：接线比写引擎重要**
- 现状：引擎完整（`schedule_adapter_spec.dart` 5 种抽取器 + 正则预编译 + 强制 https；`schedule_adapter_engine.dart` 变量袋/Cookie 袋/8MB 与 5000 行上限/重定向拒绝/GB 编码明确报错），**但零调用点、零脚本**（正控见 A.4）。
- 市场验证过的低成本路线是**嘎嘎的做法**：不是 1542 个适配器，而是 `schools.json` = `[校名, 系统类型, URL]` 三元组 + 10 条 URL 正则指纹 + 只有正方写专用接口脚本、其余全部落到**通用 HTML 表格解析**。我们的 `html_table_extractor.dart`（400 行）已经在做通用表格解析，缺的只是学校索引 + 指纹表 + 登录 WebView。**2026-10-11 更新**：抽取器已经有了第一个调用方 —— 导入页「粘贴 / 选 .html 文件」经 `html_schedule_parser.dart` 走通用表格解析，与教务 Excel 共用同一套网格判据；但**抓取侧（引擎 + 登录）仍然零接线**，本条没收口。
- 索引来源可直接用 `baoozak/timetable` 的 schools（MIT，嘎嘎正是这么用的，见其 `README.md:115` 的署名方式）。
- 建议顺序：① 把引擎接到 UI（凭据录入 → 选校 → 选学期 → 预览 → 确认写入，沿用现有 `Noop` 的诚实文案位）；② 内置系统指纹表 + 学校索引；③ 先只落 1-2 种系统（强智/正方）打通端到端，其余走 HTML 粘贴导入。
