# 好学云谱云端数据中心

目标模式：

```text
本站账号认证(自管,邀请制注册)
        ↓
好学云谱 Docker 后端
        ↓
Web / 手机 APK / 电脑版
```

## 数据互通范围

同一个账号登录后，以下数据会同步到 Docker 后端，并在 Web、手机端、电脑端之间互通：

- 家族资料
- 人物成员
- 人生事件
- 谱序、题词、纸质家谱、影像附件等谱牒资料
- 设置项
- 快照备份

本机 IndexedDB 仍会保留一份离线缓存。离线时可以继续查看最近一次同步的数据；联网后会继续推送编辑内容。

## Docker 启动

```powershell
docker compose up -d --build
```

默认地址：

```text
http://localhost:5173
```

`JIAPU_AUTH_SECRET` 留空即可——服务端首次启动会自动生成随机密钥并存入数据卷（`yunpu-data:/app/data/.session-secret`），每实例唯一、重启复用，新手无需配置。多实例或自建想固定密钥时再手动设置。建议通过 HTTPS 域名反向代理到容器。

云端数据保存在 Docker volume：

```text
yunpu-data:/app/data
```

账号数据文件位于容器内：

```text
/app/data/users.json        # 账号表(用户名/邮箱/scrypt 密码哈希)
/app/data/accounts          # 每账号谱数据
/app/data/collaboration     # 家族协作授权表与邀请码
```

## 高级配置（可选环境变量）

发给最终用户的 `docker-compose.example.yml` 是**零配置**模板（只含端口、自动密钥、可选 OTA）。下面这些是自建/运维场景才用的高级项,默认无需填写。要启用就在 compose 的 `environment` 或 `.env` 里加:

| 变量 | 说明 | 默认 |
|---|---|---|
| `JIAPU_AUTH_DISABLED` | `1` 关闭鉴权(仅开发,生产保持 0) | `0` |
| `JIAPU_OPEN_REGISTRATION` | `1` 开放任何人免码注册;默认邀请制(族人凭族长邀请码注册) | `0` |
| `JIAPU_CORS_ORIGINS` | 允许携带凭证的额外前端来源(逗号分隔;同源无需配) | 空 |
| `YUNPU_API_BASE` | 前端 API 基址(反代/独立域名部署时填) | 空 |
| `YUNPU_UPDATE_MANIFEST_URL` | OTA 更新清单地址(留空则客户端「检查更新」提示未配置) | 空 |

## 账号与注册

账号由本系统自管,不依赖任何外部站点:

- **存储**:`data/users.json`(scrypt 密码哈希,原子写);每用户谱数据仍按账号哈希存于 `data/accounts/`。
- **首位注册者即管理员**:首次打开登录页会提示「创建管理员账号」。
- **邀请制注册**:管理员/族长在「设置 → 协作」生成邀请码(选角色/有效期/次数),族人凭码在登录页注册,注册完成自动以所选角色加入家族。
- **开放注册**(可选):`JIAPU_OPEN_REGISTRATION=1` 后任何人可免码注册。
- **忘记密码**:服务器上执行 `node scripts/reset-password.mjs <用户名>`(Docker 内 `docker compose exec app node scripts/reset-password.mjs <用户名>`),无邮件依赖。

> 注:`JIAPU_AUTH_SECRET` 留空时,服务端自动生成随机密钥并落盘 `.session-secret`(0600 权限,原子写入)。设置时必须 ≥32 字符且不能是占位词(如 `change-this`/`secret...`),否则拒绝启动。

## Web 端

Web 端直接访问 Docker 后端地址即可。因为前端和 API 同源，`runtime-config.js` 可以保持默认空地址。

## 手机端 / APK

手机端不需要为每个用户单独打包后端地址。登录界面会显示“云端地址”，用户填写自己部署的 Docker 后端即可，例如：

```text
https://yunpu.example.com
http://192.168.1.10:5173
```

如果希望给 APK 预填一个默认地址，可以在打包前设置：

```powershell
$env:YUNPU_CLOUD_URL="https://yunpu.example.com"
npm run package:apk
```

也兼容旧变量名：

```powershell
$env:YUNPU_MOBILE_API_BASE="https://yunpu.example.com"
npm run package:apk
```

## 电脑版

电脑版同样可以在登录界面填写“云端地址”。如果希望预填默认地址，可以通过环境变量指定：

```powershell
$env:YUNPU_CLOUD_URL="https://yunpu.example.com"
npm run package:desktop-exe
```

也可以在运行目录放置 `runtime-config.local.json`：

```json
{
  "apiBase": "https://yunpu.example.com"
}
```

## 同步接口

登录认证：

```text
GET  /api/auth/registration-info   注册模式探测 {firstUser, open}(登录页决定展示形态)
POST /api/auth/register            注册 {username, password, email?, inviteCode?}(首用户免码成管理员;否则需邀请码或开放注册)
POST /api/auth/login               登录 {login(用户名或邮箱), password}
GET  /api/auth/session             会话探测
POST /api/auth/logout              退出
POST /api/auth/password            改自己密码 {oldPassword, newPassword}
```

家族邀请码(协作面板用,owner 专用):

```text
GET    /api/collab/families/:id/invites          邀请码列表
POST   /api/collab/families/:id/invites          生成 {role, expiresInDays?, maxUses?}
DELETE /api/collab/families/:id/invites?code=X   作废
```

云端数据：

```text
GET    /api/sync/state
PUT    /api/sync/state
DELETE /api/sync/state
```

客户端登录后会保存 token，并在同步请求中使用：

```http
Authorization: Bearer <token>
```

`PUT /api/sync/state` 带 `baseRevision`，用于检测多端并发编辑。如果云端 revision 已变化，后端返回 `409`，客户端会合并后重试。

## 只读分享接口

```text
POST   /api/share                 创建（需登录）  body: {familyId, days, label?, includeDocuments?}
GET    /api/share                 我可见的链接列表（需登录，不回带 token）
DELETE /api/share/<id>            撤回（需登录，只有创建者或家族所有者）
GET    /api/share/view/<token>    免登录读取全谱（唯一不需要凭证的入口）
```

口径与限制，排障前先对齐这几条：

- **`days` 只能是 1 / 7 / 30**，其它值一律 400。这是刻意的白名单，不是漏了校验。
- 服务端只存 token 的 **sha256**，完整 token 只在创建成功的那一次响应里出现；列表接口永远拿不到它。丢了就重新建一条。
- 载荷字段是**白名单**：在世成员（未标已故且无卒年）的照片、相册、生平、备注、职业、民族、籍贯、出处、核定向导都不出公开通道；已故成员按谱书照常给。以后给成员加新字段，默认**不会**出现在分享里，要公开得显式加进 `SHARE_MEMBER_FIELDS`。
- 谱牒影像与释文默认不进；`includeDocuments: true` 只多给一份标题级目录。
- 撤回 = 删除文件 + 清掉 30 秒载荷缓存，所以撤回后访客立刻看到 404，不会出现「已经撤回了但还能读半分钟」。
- 免登录入口按 IP 限流（60 次/分钟），超限 429；响应带 `Cache-Control: no-store` 与 `X-Robots-Tag: noindex`。
- 数据权威副本在家族所有者那里：协作者创建链接时，存在性检查与载荷都按所有者副本取，不是取创建者自己的云文件。
