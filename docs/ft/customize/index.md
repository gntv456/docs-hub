# 自定义手册（customize）

站长「不写代码改产品」的六个入口。全部在后台完成、即时生效。

1. [用户字段](/ft/customize/user-fields)：注册表单/档案/筛选的自定义字段
2. [内容维度](/ft/customize/sections)：种子分类树与维度字段（同引擎双端）
3. [自定义页面与菜单](/ft/customize/pages-menus)：规则页/FAQ/落地页
4. [站型与术语](/ft/customize/site-type)：11 种预置站型、另存快照、术语改名
5. [内容包与主题](/ft/customize/packs-themes)：生态商店内容包、主题令牌
6. [模块开关与面板](/ft/customize/modules)：30 个模块的启停联动
7. [适配器](/ft/customize/adapters)：wasmtime 沙箱适配器（外部数据源接入）
8. [翻译与多语言](/ft/customize/translating)：语言切换/术语表分工/翻译贡献指南
