# 好学探索 · 产品策划文档

> 版本：v0.1 · 状态：策划定稿 · 日期：2026-07-26  
> 定位：**私有化部署的短视频/短剧探索终端** —— 把 NAS、网盘、PT 与寸光集资源，做成抖音/快手/小红书/抖音精选式沉浸体验。

---

## 1. 产品一句话

**好学探索**让用户用熟悉的「上下滑刷视频」方式，消费自己 NAS/网盘/PT 站点里的视频与短剧；支持点赞评论收藏、分类显隐、随手拍，并一键刮削豆瓣/TMDB/PT/寸光集元数据。账号复用 **好学 PT（hxpt）** 或 **寸光集（ptang.top）**，登录链路对齐 `D:\jiapu`。

---

## 2. 目标用户与场景

| 用户 | 核心场景 | 价值 |
|------|----------|------|
| 家庭 NAS 用户 | 把硬盘里的电影/短剧/剪辑变成沉浸 Feed | 不用再翻文件夹 |
| PT 站用户 | 好学 PT / 寸光集资源浏览 + 刮削 | 账号统一，元数据完整 |
| 内容整理者 | 自定义分类/文件夹/显隐 | 像相册一样管理视频库 |
| 轻创作者 | 随手拍上传到私有库 | 家庭/小团队 UGC 闭环 |

**非目标（MVP 不做）**
- 公网推荐算法广告系统
- 商业直播带货
- 全网爬虫盗链第三方版权平台正片

## 5. 核心功能规格（MVP → v1）

### 5.1 账号登录（P0）

参考 `D:\jiapu` 的多源认证链：

1. **在线优先**
   - 邮箱 → 优先寸光集在线 `POST https://ptang.top/api/auth/login`
   - 用户名 → 优先好学在线 challenge + takelogin（SHA256 + HMAC）
2. **本地回退**
   - 好学 MySQL `users` 表校验
   - 寸光集 SQLite/PG 校验
3. **会话**
   - HMAC 签名 Cookie / Bearer Token
   - 30 天有效，支持两步验证码
4. **前端**
   - 登录页可填 API Base（移动端/桌面端）
   - 会话缓存，弱网可进已缓存界面

### 5.2 资源接入（P0）

| 源类型 | 接入方式 | 说明 |
|--------|----------|------|
| 本地/NAS 挂载 | Docker volume / bind mount | 如 `/media/nas/movies` |
| WebDAV | 账号+URL | 群晖/群晖 Drive/坚果云 |
| SMB（后续） | 挂载后读 | 建议宿主机挂载后映射 |
| 网盘（阿里/115 等） | 经 Alist/OpenList WebDAV | 不直接对接各网盘 SDK（MVP） |
| PT/寸光集索引 | API/RSS/本地库 | 元数据 + 可选下载路径映射 |

**资源索引器**定时扫描：
- 识别视频后缀：`mp4/mkv/ts/m2ts/mov/webm/avi`
- 提取：路径、大小、时长、分辨率、缩略图、所在分类
- 变化检测：inode/mtime/size 增量扫描

### 5.3 刷视频 Feed（P0）

交互对齐抖音/快手：
- 全屏竖滑（一个视频一屏）
- 自动播放 / 滑走暂停
- 右侧：点赞、评论、收藏、分享（复制链接/路径）、更多
- 双击点赞动效
- 底部：标题、分类、来源徽章（NAS/网盘/PT/随手拍）
- 进度条可拖
- 横屏电影可「展开详情」或「横屏播放」

内容池规则（MVP 简单可解释）：
1. 仅展示「可见分类」下的资源
2. 优先未看完 / 最近入库
3. 同系列短剧连续聚合（刮削后）
4. 用户可切换：精选 / 分类 / 文件夹 / 收藏

### 5.4 点赞 · 评论 · 收藏（P0）

- 按账号隔离社交数据（同一 Docker 实例多用户）
- 点赞：切换态 + 计数
- 收藏：可进自定义收藏夹
- 评论：楼中楼 1 层（MVP），支持删除自己的评论
- 历史：播放进度记忆，下次续播

### 5.5 分类 / 文件夹 / 显隐（P0）

- **物理文件夹**：来自 NAS/网盘真实路径
- **逻辑分类**：用户自建（如「短剧」「纪录片」「孩子」）
- 一个视频可属于多个逻辑分类
- 每个分类有：`visible` 开关；关闭后 Feed/发现均不出现
- 支持排序、图标、封面

### 5.6 随手拍（P1）

- 调用设备摄像头拍照/录像（Web：`getUserMedia`；App：Capacitor Camera）
- 本地预览 → 选分类 → 上传 `POST /api/capture`
- 存储到 `data/uploads/{userId}/`
- 自动进入索引与 Feed（标记来源=随手拍）

### 5.7 刮削（P0 短剧/视频）

| 源 | 用途 | 关键字段 |
|----|------|----------|
| 豆瓣 | 中文影视/短剧 | 标题、评分、简介、演员、海报 |
| TMDB | 国际影视标准 ID | title、overview、poster、season/episode |
| PT 站点 | 种子/发布页标题与标签 | 标题、类目、IMDb/豆瓣链接 |
| 寸光集 ptang.top | 站内资源元数据 | 标题、封面、描述、标签 |

刮削流程：
1. 用户对手动条目或批量目录发起刮削
2. 文件名清洗（去码率/组名/分辨率）→ 生成搜索词
3. 多源并行检索 → 用户确认或自动匹配（置信度阈值）
4. 写入元数据库，刷新封面/简介/分集
5. 短剧：识别 `SxxExx` / `第N集`，聚合为剧集 Feed

### 5.8 UI：iOS 27 风格（P0 视觉）

关键词：**Liquid Glass / 大圆角 / 毛玻璃 / 动态高光 / 系统级留白**

- 背景：多层模糊渐变 + 微噪声
- 控件：半透明材质、细描边、柔和外阴影
- 导航：底部悬浮 Tab（毛玻璃胶囊）
- 动效：弹簧阻尼、页面推入淡化
- 深浅色自动跟随系统
- 字体：系统 SF 风格栈（`-apple-system, "SF Pro", "PingFang SC"`）
- 安全区：刘海/Home Indicator 适配

## 5.9 多端形态（P0 规划，分阶段交付）

必须覆盖五端，详细见 [`docs/多端方案.md`](/tanqu/多端方案)：

| 端 | 形态 | 技术 | 阶段 |
|----|------|------|------|
| **Web 端** | 浏览器 / PWA | Docker 托管前端 | v0.1 |
| **电脑端** | Windows / macOS / Linux 安装包 | Electron 壳 + 共享 UI | v0.2 |
| **手机端** | Android APK/AAB | Capacitor | v0.2 |
| **鸿蒙端** | HarmonyOS NEXT | ArkWeb 容器 + 原生桥 | v0.3 |
| **iOS 端** | IPA / TestFlight / App Store | Capacitor iOS | v0.4 |

**统一体验约束**
- 同一套 iOS27 液态玻璃 UI 与信息架构
- 同一 Docker 后端与好学/寸光集登录
- 各端仅实现相机、安全存储、窗口等原生桥
- 宽屏（电脑/Web 桌面）可左库右刷；窄屏全屏竖滑
## 6. 用户旅程（关键路径）

### 旅程 A：首次部署到刷到第一个视频
1. `docker compose up -d`
2. 浏览器打开 `http://host:8787`
3. 用好学/寸光集账号登录
4. 设置 → 添加媒体目录（已挂载 NAS 路径）
5. 触发扫描 → 进入 Feed 上下滑

### 旅程 B：短剧刮削
1. 片库选中「短剧」文件夹
2. 批量刮削 → 选豆瓣/TMDB
3. 确认匹配 → 自动分集
4. Feed 中连续刷同一部短剧

### 旅程 C：随手拍
1. 点中间拍摄按钮
2. 录 15s → 选分类「家庭」
3. 上传成功后出现在 Feed 与「最近拍摄」

## 9. 商业与合规边界（产品原则）

1. **只服务用户合法拥有或被授权访问的资源**
2. 刮削仅取公开元数据（海报/简介），不镜像盗链正片
3. PT/寸光集登录仅作身份校验与授权元数据，不存储明文密码
4. 私有化部署数据默认留在用户设备/NAS

## 10. 成功指标（上线 30 天）

- 首次扫描到可播视频成功率 ≥ 95%
