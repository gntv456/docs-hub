# 短剧剧场（红果 / 河马剧场风格）

## 产品对标
- **红果短剧**：热播榜、继续观看、竖屏沉浸连播、分集选择
- **河马剧场**：海报墙、标签、剧集详情、分集网格

## 页面结构
1. 顶部 Hero：好学剧场品牌区
2. 榜单 Chips：热播榜 / 新剧速递 / 多集连载
3. 货架：
   - 继续观看（横滑大卡）
   - 编辑精选（海报）
   - 猜你想看（海报）
4. 全部短剧双列/四列海报墙（TOP 角标、更新至第 N 集）
5. 剧集详情 Sheet：封面、标签、简介、分集网格、续播按钮
6. 播放：进入竖滑 Feed，按分集队列连播

## API
- `GET /api/drama/home?rank=hot|new|finish`
- `GET /api/drama/series/:id`

## 入库建议
- 文件放入 `data/media/shorts` 或 NAS 短剧目录
- 文件名含 `第N集` / `S01E02` / `E01` 以便自动聚合剧集
